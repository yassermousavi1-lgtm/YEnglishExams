1. PROJECT OVERVIEW
================================================================================

YEnglish Exams is a complete Telegram-based English examination system for
private English classes. It allows teachers to create exams, manage students,
and send tests to Telegram groups without any coding knowledge.

The system runs 24/7 on a free cloud server (PythonAnywhere) and is fully
accessible through Telegram Mini Apps.

================================================================================
2. WHAT THE SYSTEM DOES
================================================================================

FOR TEACHERS:
------------
- View list of all students
- Add new students with their Telegram User ID
- View list of all exams
- Create exams with JSON-formatted questions
- Assign exams to groups
- Send exams to Telegram groups
- View student results and scores

FOR STUDENTS:
-------------
- Open exams directly from Telegram group
- Auto-authentication via Telegram
- Answer questions one at a time
- Navigate forward/backward
- See progress bar
- See countdown timer
- Submit exam and see result immediately

4. DATABASE STRUCTURE
================================================================================

DATABASE: exam.db

TABLES:
--------
1. groups
   - id (INTEGER PRIMARY KEY)
   - telegram_group_id (INTEGER UNIQUE)
   - name (TEXT)

2. students
   - id (INTEGER PRIMARY KEY)
   - telegram_user_id (INTEGER UNIQUE)
   - first_name (TEXT)
   - last_name (TEXT)
   - username (TEXT)
   - group_id (INTEGER FOREIGN KEY)

3. questions
   - id (INTEGER PRIMARY KEY)
   - question_text (TEXT)
   - option_a (TEXT)
   - option_b (TEXT)
   - option_c (TEXT)
   - option_d (TEXT)
   - correct_answer (TEXT CHECK A/B/C/D)

4. exams
   - id (INTEGER PRIMARY KEY)
   - title (TEXT)
   - time_limit (INTEGER)

5. exam_questions
   - id (INTEGER PRIMARY KEY)
   - exam_id (INTEGER FOREIGN KEY)
   - question_id (INTEGER FOREIGN KEY)
   - question_order (INTEGER)

6. exam_assignments
   - id (INTEGER PRIMARY KEY)
   - exam_id (INTEGER FOREIGN KEY)
   - group_id (INTEGER FOREIGN KEY)
   - assigned_at (TIMESTAMP)

7. results
   - id (INTEGER PRIMARY KEY)
   - student_id (INTEGER FOREIGN KEY)
   - exam_id (INTEGER FOREIGN KEY)
   - score (INTEGER)
   - total_questions (INTEGER)
   - started_at (TEXT)
   - completed_at (TEXT)

6. API ENDPOINTS
================================================================================

PUBLIC ENDPOINTS:
-----------------
GET  /                            → Serves Mini App (index.html)
GET  /api                         → Health check
GET  /api/me                      → Authenticate user and get role
GET  /api/exam/<exam_id>          → Get exam info (student only)
GET  /api/exam/<exam_id>/questions→ Get exam questions (no answers)
POST /api/exam/submit             → Submit exam and grade

TEACHER ENDPOINTS:
-----------------
GET    /api/teacher/students              → List all students
POST   /api/teacher/students              → Add new student
GET    /api/teacher/groups                → List all groups
GET    /api/teacher/questions             → List all questions
GET    /api/teacher/exams                 → List all exams
GET    /api/teacher/assignments           → List all assignments
GET    /api/teacher/results               → List all results
POST   /api/teacher/exams_with_questions  → Create exam from JSON
POST   /api/teacher/assign_exam           → Assign exam to group
POST   /api/teacher/send_exam_by_exam_id  → Send exam to group

7. HOW TO USE THE TEACHER PANEL (IN TELEGRAM)
================================================================================

STEP 1: Open your bot in Telegram
Bot username: @YEnglsihExamsbot

STEP 2: Click the "Start Exam" button
This opens the Teacher Panel Mini App

STEP 3: Available actions in the panel:

7.1 - VIEW STUDENTS
Click "👥 Students" → See all registered students

7.2 - ADD STUDENT
Click "➕ Add Student" → Fill in the form
- First Name: Student's name
- Telegram User ID: Get from @userinfobot
- Group ID: 1 (for Test's English class)

7.3 - VIEW EXAMS
Click "📝 Exams" → See all created exams with their ID

7.4 - CREATE EXAM
Click "📝 Create Exam" → Fill in:
- Exam Title: Name of the exam
- Total Time: Duration in minutes
- Number of Questions: Count of questions
- JSON Field: Paste questions in JSON format

JSON Format Example:
[
  {
    "question_text": "What is the capital of France?",
    "option_a": "Berlin",
    "option_b": "Madrid",
    "option_c": "Paris",
    "option_d": "Rome",
    "correct_answer": "C"
  }
]

7.5 - SEND EXAM
Click "📤 Send Exam" → See all exams
- If not assigned: Click "📌 Assign & Send" → Exam sent to group
- If already assigned: Click "📤 Send" → Exam sent to group

7.6 - VIEW RESULTS
Click "📊 Results" → See all student exam results

9. HOW TO CREATE QUESTIONS USING AI
================================================================================

STEP 1: Ask ChatGPT or Claude to generate questions in JSON format

STEP 4: Fill in:
- Exam Title: e.g., "Present Simple Quiz"
- Total Time: e.g., 5
- Number of Questions: e.g., 5
- Paste the JSON in the text area

STEP 5: Click "Create Exam"

16. TROUBLESHOOTING
================================================================================

PROBLEM: "Telegram Bot Token is not configured"
SOLUTION: Set TELEGRAM_BOT_TOKEN in environment variables or wsgi.py

PROBLEM: "Exam ID was not received from Telegram"
SOLUTION: Use deep link with startapp parameter
         Example: https://t.me/YEnglsihExamsbot?startapp=exam_2

PROBLEM: "No module named telegram"
SOLUTION: Run: pip install python-telegram-bot --user

PROBLEM: ngrok shows "ERR_NGROK_3200"
SOLUTION: ngrok has stopped. Run ngrok http 5000 again

PROBLEM: Git shows "Author identity unknown"
SOLUTION: Set name and email:
         git config --global user.name "Your Name"
         git config --global user.email "you@example.com"

PROBLEM: Web app not showing changes
SOLUTION: Go to Web tab → Click Reload
